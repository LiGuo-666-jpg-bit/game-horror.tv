# 📺 电视模拟恐怖

> 一个纯 Python 终端恐怖游戏。零依赖，手机本地即可运行。

## 🎮 操作

| 键 | 功能 |
|---|---|
| w/↑ | 上一频道 |
| s/↓ | 下一频道 |
| d/→ | 音量+ |
| a/← | 音量- |
| t | 开关电视 |
| l | 环顾 |
| f | 手电筒 |
| o | 门锁 |
| v | 窗户 |
| p | 电话 |
| i | 物品栏 |
| m | 静音 |
| c | 频道列表 |
| h | 帮助 |
| q | 退出 |

## 📡 频道

- CH00 雪花屏
- CH01-CH12 常规频道（新闻/卡通/购物/纪录片...）
- CH13 ??? 他在你身后
- CH14 ??? 直播你的房间
- CH15 ??? I AM HERE
- CH16 ??? I AM YOUR NEXT

## 💀 结局

8种结局等你发现。天亮是真正的终点。

## 🏃 运行

```bash
python main.py
```

需要 Python 3.8+。无需安装任何第三方库。

## ⚠️ 警告

不要调到频道13。
停电了别关手电筒。
锁好门。
