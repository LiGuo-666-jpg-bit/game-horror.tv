🚀 快速开始：
  方式一：直接运行完整游戏
    python main.py

  方式二：先试预告片是否能在手机上跑
    python 预告片独立运行版.py
    （如果能看到闪烁标题+制作名单+倒计时，说明环境OK）

🎬 预告片内容：
  · 第一幕：标题闪现（闪烁3次）
  · 第二幕：制作名单（"导演：你的大脑"）
  · 第三幕：警告画面（18+ / 耳机建议）
  · 第四幕：10段预告片段（越来越快，含闪烁快切）
  · 第五幕：3-2-1 倒计时 → 最终标题
  · 输入 q 可跳过预告片
