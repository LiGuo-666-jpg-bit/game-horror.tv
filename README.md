# 📺 电视模拟恐怖 · 终极中文版 v4.0

> 一部关于**电视**的 Python CLI 恐怖游戏。
> **预告片和主程序已分离为两个文件**，可独立运行也可联动。
> 纯标准库 | 零依赖 | 手机/电脑通用

## 📁 文件结构

```
game-trailer/
├── main.py        ← 主程序（游戏本体，2060+行）
├── trailer.py     ← 预告片模块（可独立运行，也可被主程序调用）
└── README.md
```

## 🚀 快速开始

### 方式一：直接玩完整版（推荐）
```bash
python main.py
```
启动后自动播放预告片 → 序章剧情 → 主游戏循环

### 方式二：只看预告片
```bash
python trailer.py
```
单独播放电影级预告片，不进入游戏

### 方式三：嵌入你自己的项目
```python
from trailer import show_trailer
# 在你的代码里任何位置调用
show_trailer()  # 播完自动返回
```

## 🎮 操作（主程序）

| 按键 | 功能 | 按键 | 功能 |
|------|------|------|------|
| `w`/`↑` | 上一频道 | `s`/`↓` | 下一频道 |
| `d`/`→` | 音量+ | `a`/`←` | 音量- |
| `t`/`Enter` | 开关电视 | `l` | 环顾 |
| `f` | 手电筒 | `o` | 门锁 |
| `v` | 窗户 | `p` | 电话 |
| `i` | 物品栏 | `c` | 频道表 |
| `m` | 静音 | `h` | 帮助 |
| `q` | 退出 | | |
