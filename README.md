# 📺 电视模拟恐怖 · 终极中文版 v4.0

> 一部关于**电视**的 Python CLI 恐怖游戏。
> 纯标准库 | 零依赖 | 手机/电脑通用

## 🎬 开场

你一个人住在13楼。昨晚电视自己开了，屏幕里出现一个空房间和一面镜子，镜子里没有你。你拔了电源，但感觉它还会回来。

今晚你决定不再逃避。

## 🚀 快速开始

```bash
git clone https://github.com/LiGuo-666-jpg-bit/game-trailer.git
cd game-trailer
python main.py
```

## 🎮 操作

| 按键 | 功能 | 按键 | 功能 |
|------|------|------|------|
| `w`/`↑` | 上一频道 | `s`/`↓` | 下一频道 |
| `d`/`→` | 音量+ | `a`/`←` | 音量- |
| `t` | 开关电视 | `l` | 环顾 |
| `f` | 手电筒 | `o` | 门锁 |
| `v` | 窗户 | `p` | 电话 |
| `i` | 物品栏 | `c` | 频道表 |
| `m` | 静音 | `h` | 帮助 |
| `q` | 退出 | | |

## 📡 17 频道 · 💀 8 结局 · 🔄 多周目

详见游戏内 `c` 键查看频道表。

## ⚠️ 忠告

> 不要调到频道13。停电了别关手电筒。锁好门。
