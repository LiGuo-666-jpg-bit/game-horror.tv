**TV Analog Horror · 纯 Python 终端游戏**

## 快速开始

```bash
git clone https://github.com/LiGuo-666-jpg-bit/game-horror.tv.git
cd game-horror.tv
python main.py
```

需要 Python 3.8+，手机/电脑通用。
