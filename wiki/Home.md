# game-horror.tv — 电视模拟恐怖

> 一款纯 Python 终端恐怖游戏。没有图形、没有音效、没有第三方库——全靠 `print()` 和 `input()` 让你的大脑填补恐惧。

## 快速开始

```bash
git clone https://github.com/LiGuo-666-jpg-bit/game-horror.tv.git
cd game-horror.tv
python main.py
```

需要 Python 3.8+，零依赖。

## 游戏简介

深夜，你独自在家。电视开着。频道在跳。有些频道不该被看到。有些东西不该被唤醒。

撑到天亮，或者……成为下一个频道。

## 版本历史

- **v10.5** — 当前版本。完整频道系统、道具系统、多周目、存档、拨号隐藏结局。

## 技术栈

- 语言：Python 3.8+
- 依赖：**零**（仅标准库 `random / time / sys / os / json`）
- 平台：Windows / Linux / macOS / Termux（手机）
- 界面：纯终端（ANSI 颜色 + Unicode 字符）
