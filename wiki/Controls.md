## 游戏内按键

| 按键 | 功能 |
|---|---|
| `w` | 调高音量 |
| `s` | 调低音量 |
| `d` | 切换到下一个频道 |
| `a` | 切换到上一个频道 |
| `t` | 开关电视 |
| `l` | 锁门/开锁 |
| `o` | 打开窗户 |
| `v` | 查看物品栏 |
| `i` | 使用物品 |
| `p` | 暂停菜单 |
| `~~` | 打开开发者控制台（仅作者账号） |

## 拨号系统

在暂停菜单中输入 `call` 进入拨号盘：

| 号码 | 效果 |
|---|---|
| `666-6666` | 触发恐怖事件（-10 理智） |
| `777-777-7777` | 触发隐藏拯救者结局 |

## 开发者控制台

输入 `~~` 调出，提供 9 个作弊指令：

1. 解锁真结局
2. 解锁被拯救
3. 满理智
4. 物品全满
5. 召唤大师
6. 跳到天亮
7. 清零脚步声
8. 全频道解锁
9. 无敌模式
